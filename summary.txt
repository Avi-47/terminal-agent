This script runs an interactive terminal agent that talks to Groq’s open‑source 20B model. It loads an API key, sets up the OpenAI client, and defines a system prompt that instructs the model to only use provided tools. In each loop the user’s prompt is added to the conversation, the model is queried with the conversation and available tools, and any returned function calls are executed via `execute_tool_call`. Results are added back to the conversation and the model can chain up to 10 tool calls per turn before printing a text reply. The program exits on `exit`/`quit` or Ctrl‑C.
